faq

Straight answers

Which files can it translate?+

It supports PDF, DOCX, TXT, and Markdown sources stored in local folders.

Does translation still need review?+

Yes. Names, tone, formatting, terminology, and culturally sensitive wording need human review before publication.

Does 3thousand30 store my documents?+

No. The selected AI provider receives the translation request; 3thousand30 does not add another cloud-storage layer.

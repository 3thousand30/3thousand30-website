personal markdown workspace // local transfer

Move a file directly between your PC and phone.

This URL is a public handoff page. The actual transfer session is created inside Personal Markdown Workspace and runs directly on your local Wi-Fi network.

01 // start

Open a note

Choose Share to phone in Personal Markdown Workspace while the note is open and unlocked.

02 // scan

Use the QR code

Keep the phone and PC on the same Wi-Fi, then scan the temporary QR code.

03 // return

Send it back

Return the same Markdown filename to update the note, or send another file as an attachment.

Your PC is the transfer server: the QR code points directly to your own computer for a short-lived same-Wi-Fi session. 3thousand30 does not receive, relay, inspect, or store the file. Password-protected notes must be unlocked on the PC before sharing. This page is intentionally not listed in the website sitemap.
